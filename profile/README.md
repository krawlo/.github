## 🛠️ Engineering Principles

- **Cost Efficiency First**: Designed to run at a fraction of standard marketplace scraper pricing without sacrificing reliability.
- **AI & Agent Ready**: Native structured JSON, clean Markdown formatting, and Model Context Protocol (MCP) compatible endpoints.
- **Anti-Bot Resilience**: Advanced browser fingerprint emulation, canvas randomization, and automated session-based IP rotation.
- **Dual Packaging**: Every scraper is architected as both an asynchronous **FastAPI Microservice** and an on-demand **Apify Actor**.
